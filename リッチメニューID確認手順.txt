============================================================
リッチメニューID確認手順書（Postman使用）
============================================================

【目的】
現在LINE公式アカウントに登録されているリッチメニューのIDを確認する。
（IDを控え忘れた場合や、削除対象のIDが分からなくなった場合に使用）

【事前に必要なもの】
・Postman（インストール済み）
・チャネルアクセストークン
  （LINE Developers Console → 対象チャネル → 「Messaging API設定」タブ
   → 「チャネルアクセストークン（長期）」）


------------------------------------------------------------
手順1：リッチメニューの一覧を取得する
------------------------------------------------------------

Postmanで新しいリクエストを作成し、以下を設定します。

■ メソッド
GET

■ URL
https://api.line.me/v2/bot/richmenu/list

■ Headers
Key           : Authorization
Value         : Bearer {channel access token}

※ Bearer の後ろに半角スペースを1つ入れ、続けてトークンを貼り付けます。
※ 左側のチェックボックスにチェックが入っていることを確認してください。

■ Body
なし（「none」のまま）

■ 実行
右上の「Send」ボタンをクリック


------------------------------------------------------------
手順2：結果を読み取る
------------------------------------------------------------

画面下部に、以下のような結果が表示されます。

{
    "richmenus": [
        {
            "richMenuId": "richmenu-xxxxxxxxxxxxxxxxxxxx",
            "name": "richmenu-pre",
            "size": { "width": 2500, "height": 1686 },
            "chatBarText": "メニュー",
            "selected": true,
            "areas": [ ... ]
        }
    ]
}

見るポイント：
・"name" が "richmenu-pre" のもの
    → 以前作成した「Aのみ版」（プレ交際）
・"name" が "richmenu-shinken" のもの
    → 真剣交際側（作成済みの場合）
・"richMenuId" の値（richmenu-で始まる文字列）
    → これが探しているIDです。メモ帳などにコピーして保管してください。

※ リッチメニューが複数存在する場合は、配列の中に複数件表示されます。
   "name" で見分けてください。


------------------------------------------------------------
手順3（任意）：現在デフォルトに設定されているメニューを確認する
------------------------------------------------------------

「今、友だち全員に実際に表示されているメニューはどれか」を確認したい場合は、
以下のリクエストを送信します。

■ メソッド
GET

■ URL
https://api.line.me/v2/bot/user/all/richmenu

■ Headers
Key           : Authorization
Value         : Bearer {channel access token}

■ Body
なし

■ 実行
「Send」をクリック

■ 返ってくる内容
{
    "richMenuId": "richmenu-xxxxxxxxxxxxxxxxxxxx"
}

この richMenuId が、現在デフォルトとして全ユーザーに表示されているメニューのIDです。
手順2の一覧と照らし合わせることで、どの名前のメニューが表示中か判別できます。

※ デフォルトメニューが1つも設定されていない場合は、
   「no default rich menu」のようなエラーメッセージが返ります。


------------------------------------------------------------
手順4：確認したIDをもとに次の作業へ進む
------------------------------------------------------------

確認できたIDは、以下の作業で使用します。

・古いリッチメニューを削除する場合
    DELETE https://api.line.me/v2/bot/richmenu/{確認したrichMenuId}

・画像を再アップロードする場合
    POST https://api-data.line.me/v2/bot/richmenu/{確認したrichMenuId}/content

・デフォルトメニューに設定する場合
    POST https://api.line.me/v2/bot/user/all/richmenu/{確認したrichMenuId}

・エイリアスを作成する場合
    POST https://api.line.me/v2/bot/richmenu/alias
    Body内の "richMenuId" に確認したIDを指定


------------------------------------------------------------
よくあるつまずきポイント
------------------------------------------------------------

症状：401 Unauthorized
原因：Authorizationヘッダーの入力ミス。
      Bearer の後ろのスペース漏れ、チェックボックスの外れ、
      Postmanの「Authorization」タブとの設定競合などを確認。

症状：richmenusの中身が空（[]）
原因：リッチメニューが1つも作成されていない、
      または別のチャネルのトークンを使っている可能性。

症状：複数のメニューが表示され、どれが現在使用中か分からない
原因：手順3のデフォルトメニュー取得APIで、
      表示中のIDを確認して照合する。
