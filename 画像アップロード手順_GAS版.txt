============================================================
リッチメニュー画像アップロード手順書（Google Apps Script版）
============================================================

【この手順書の位置づけ】
Postman・PowerShellで画像アップロードがうまくいかない場合の代替手順です。
Google Apps Script（以下GAS）は、Googleのサーバー上で動くため、
お使いのPCやネットワーク、Postmanの影響を受けずに画像を送れます。

画像アップロードの2回分（A・B）だけをGASで行います。
それ以外の手順（メニュー作成、デフォルト設定、エイリアス作成）は、
これまで通りPostmanで行って問題ありません。
（Postmanでの一覧取得・削除・メニュー作成は、すべて成功しているため）

【事前に必要なもの】
・Googleアカウント
・Aのリッチメニュー作成済みで、richMenuId_A を控えている
・Bのリッチメニュー作成済みで、richMenuId_B を控えている
・チャネルアクセストークン
・画像ファイル2枚
    richmenu-pre_final.jpg      （Aの画像）
    richmenu-shinken_final.jpg  （Bの画像）

【作業するデバイスについて】
GASのコード編集画面は、パソコンのブラウザでの操作を推奨します。
iPhoneで行う場合は、Safariの「デスクトップ用Webサイトを表示」に
切り替えてください（画面が小さく、操作が難しくなります）。


------------------------------------------------------------
手順1：画像をGoogleドライブにアップロードする
------------------------------------------------------------

1. Googleドライブ（https://drive.google.com）を開く
2. 画像2枚（_final.jpg）をアップロードする
   ・パソコン：ドライブの画面にファイルをドラッグ＆ドロップ
   ・iPhone：Googleドライブアプリの「＋」→「アップロード」
3. アップロードされたファイルを右クリック（iPhoneは「…」）
   →「リンクを取得」（または「共有」）をクリック
4. 表示されるリンクから「ファイルID」を取り出して、メモ帳に控える

■ ファイルIDの見つけ方
リンクは次の形をしています。

  https://drive.google.com/file/d/【ここがファイルID】/view?usp=sharing

「/d/」と「/view」の間の文字列が、ファイルIDです。
Aの画像のID と、Bの画像のID を、それぞれ控えてください。

※ 共有設定を「リンクを知っている全員」に変更する必要はありません。
  自分のドライブ内のファイルは、そのままスクリプトから読み込めます。


------------------------------------------------------------
手順2：GASのプロジェクトを作る
------------------------------------------------------------

1. https://script.google.com を開く（同じGoogleアカウントでログイン）
2. 左上の「新しいプロジェクト」をクリック
3. 画面左上の「無題のプロジェクト」をクリックし、
   「リッチメニュー画像アップロード」などの名前に変更する
4. エディタに最初から入っているコード（function myFunction() { } ）を
   すべて削除する


------------------------------------------------------------
手順3：コードを貼り付ける
------------------------------------------------------------

以下のコードを、すべて貼り付けて、
画面上部のフロッピーディスクのアイコン（保存）をクリックします。

※ このコードの中には、トークンやIDを書き込みません。
  それらは、手順4の「スクリプトプロパティ」で別に設定します。
  （コードにトークンを直接書くと、漏えいのリスクが高まるためです）

function getConfig_() {
  var p = PropertiesService.getScriptProperties();
  return {
    token: p.getProperty('TOKEN'),
    idA: p.getProperty('ID_A'),
    idB: p.getProperty('ID_B'),
    fileA: p.getProperty('FILE_ID_A'),
    fileB: p.getProperty('FILE_ID_B')
  };
}

// リッチメニューの一覧を表示する（動作確認用）
function listMenus() {
  var c = getConfig_();
  var res = UrlFetchApp.fetch('https://api.line.me/v2/bot/richmenu/list', {
    method: 'get',
    headers: { Authorization: 'Bearer ' + c.token },
    muteHttpExceptions: true
  });
  Logger.log('ステータス: ' + res.getResponseCode());
  if (res.getResponseCode() !== 200) {
    Logger.log('レスポンス: ' + res.getContentText());
    return;
  }
  var data = JSON.parse(res.getContentText());
  var menus = data.richmenus || [];
  Logger.log('メニュー数: ' + menus.length);
  menus.forEach(function (m) {
    Logger.log(m.richMenuId + ' / ' + m.name);
  });
}

// 画像をアップロードする共通処理
function uploadImage_(richMenuId, fileId, token) {
  var bytes = DriveApp.getFileById(fileId).getBlob().getBytes();
  Logger.log('送信するファイルサイズ: ' + bytes.length + ' bytes');

  var res = UrlFetchApp.fetch(
    'https://api-data.line.me/v2/bot/richmenu/' + richMenuId + '/content',
    {
      method: 'post',
      contentType: 'image/jpeg',
      headers: { Authorization: 'Bearer ' + token },
      payload: bytes,
      muteHttpExceptions: true
    }
  );
  Logger.log('ステータス: ' + res.getResponseCode());
  Logger.log('レスポンス: ' + res.getContentText());
}

// Aの画像をアップロード
function uploadA() {
  var c = getConfig_();
  uploadImage_(c.idA, c.fileA, c.token);
}

// Bの画像をアップロード
function uploadB() {
  var c = getConfig_();
  uploadImage_(c.idB, c.fileB, c.token);
}

// 画像が登録済みか確認する共通処理
function checkImage_(richMenuId, token) {
  var res = UrlFetchApp.fetch(
    'https://api-data.line.me/v2/bot/richmenu/' + richMenuId + '/content',
    {
      method: 'get',
      headers: { Authorization: 'Bearer ' + token },
      muteHttpExceptions: true
    }
  );
  var code = res.getResponseCode();
  Logger.log('ステータス: ' + code);
  if (code === 200) {
    Logger.log('画像は登録済みです（サイズ: ' + res.getBlob().getBytes().length + ' bytes）');
  } else if (code === 404) {
    Logger.log('画像は未登録です');
  } else {
    Logger.log('レスポンス: ' + res.getContentText());
  }
}

function checkImageA() {
  var c = getConfig_();
  checkImage_(c.idA, c.token);
}

function checkImageB() {
  var c = getConfig_();
  checkImage_(c.idB, c.token);
}

------------------------------------------------------------
手順4：トークンとIDを「スクリプトプロパティ」に登録する
------------------------------------------------------------

1. 画面左側の歯車アイコン「プロジェクトの設定」をクリック
2. 下へスクロールし、「スクリプト プロパティ」の
   「スクリプト プロパティを追加」をクリック
3. 次の5つを、1つずつ登録する（プロパティ名は大文字・半角で正確に）

   プロパティ名      値
   ------------------------------------------------------
   TOKEN            チャネルアクセストークン
   ID_A             Aのリッチメニューid（richmenu-で始まる文字列）
   ID_B             Bのリッチメニューid（richmenu-で始まる文字列）
   FILE_ID_A        手順1で控えた、Aの画像のファイルID
   FILE_ID_B        手順1で控えた、Bの画像のファイルID

4. 「スクリプト プロパティを保存」をクリック

※ 値の前後にスペースや改行が入らないよう注意してください。
※ 値に「"」や「{ }」は付けません。文字列だけを入力します。


------------------------------------------------------------
手順5：動作確認（メニュー一覧の取得）
------------------------------------------------------------

まず、トークンとIDが正しいか確認します。

1. 画面左側の「エディタ」（</>のアイコン）に戻る
2. 画面上部の関数選択のプルダウンから「listMenus」を選ぶ
3. 「実行」ボタンをクリック

■ 初回のみ：権限の承認が求められます
1. 「承認が必要です」と表示 →「権限を確認」をクリック
2. Googleアカウントを選択
3. 「このアプリはGoogleで確認されていません」と表示された場合
   →「詳細」をクリック
   →「（プロジェクト名）（安全ではないページ）に移動」をクリック
4. 「許可」をクリック

※ これは、ご自身で作ったスクリプトに権限を与える操作なので、
  この警告が出るのは正常です。
  承認するのは、「Googleドライブのファイルの閲覧」と
  「外部サービスへの接続」の2点です。

■ 結果の見方
画面下部の「実行ログ」に、次のように表示されます。

  ステータス: 200
  メニュー数: 2
  richmenu-xxxxxxxx... / richmenu-pre
  richmenu-yyyyyyyy... / richmenu-shinken

・ステータスが200で、ID_A・ID_B と同じIDが一覧にあれば、正常です。
・ステータスが401の場合：TOKENの値が違います（手順4を確認）。
・一覧に ID_A・ID_B がない場合：IDが違います。一覧のIDを使って
  手順4をやり直してください。


------------------------------------------------------------
手順6：Aの画像をアップロードする
------------------------------------------------------------

1. 関数選択のプルダウンから「uploadA」を選ぶ
2. 「実行」ボタンをクリック
3. 画面下部の実行ログを確認する

■ 成功した場合
  送信するファイルサイズ: 417455 bytes
  ステータス: 200
  レスポンス: {}

・「ステータス: 200」が出ていれば、成功です。
・ファイルサイズが 417455 と表示されれば、正しい画像が送られています。
  （この値が違う場合は、ドライブにあるファイルが、
   お渡ししたものと異なる可能性があります）


------------------------------------------------------------
手順7：Bの画像をアップロードする
------------------------------------------------------------

1. 関数選択のプルダウンから「uploadB」を選ぶ
2. 「実行」ボタンをクリック
3. 実行ログを確認する

■ 成功した場合
  送信するファイルサイズ: 465959 bytes
  ステータス: 200
  レスポンス: {}


------------------------------------------------------------
手順8：アップロード結果を確認する（任意）
------------------------------------------------------------

関数「checkImageA」「checkImageB」を、それぞれ実行します。

■ 結果の見方
  ステータス: 200
  画像は登録済みです（サイズ: ○○○○○ bytes）

と表示されれば、LINEのサーバーに画像が保存されています。
「画像は未登録です」と表示された場合は、アップロードに失敗しています。


------------------------------------------------------------
手順9：Postmanの作業に戻る
------------------------------------------------------------

画像のアップロードが完了したら、Postmanで以下の続きを行ってください。

1. デフォルトメニューの設定（Aを全員に表示）
2. エイリアスの作成（richmenu-alias-pre と richmenu-alias-shinken の2つ）

※ すでに完了している手順はスキップして構いません。


------------------------------------------------------------
手順10：作業後の後片付け（セキュリティ）
------------------------------------------------------------

トークンはチャネルを操作できる「鍵」です。作業が終わったら、
次のいずれかを行ってください。

・プロジェクトの設定で、スクリプトプロパティの「TOKEN」を削除する
・LINE Developers Consoleでチャネルアクセストークンを再発行する
  （古いトークンは無効になります）
・このGASプロジェクトを削除する

※ GASのプロジェクトは、他人と共有しないでください。
  共有すると、保存したトークンが見える場合があります。


------------------------------------------------------------
つまずきやすいポイント
------------------------------------------------------------

症状：ステータス 401
原因：TOKENの値の入力ミス、またはコピー漏れ。
      手順4でTOKENを入れ直してください。

症状：ステータス 403
原因：レスポンスの文章に理由が出ます。実行ログの「レスポンス:」の
      文章を確認してください。
      メニューIDが別チャネルのものだった場合や、
      画像が登録済みの場合などが考えられます。
      手順5の一覧、手順8の確認結果と、レスポンスの文章を
      照らし合わせてください。

症状：ステータス 404
原因：メニューIDが違う、または削除済み。
      手順5の一覧から、正しいIDを確認してください。

症状：ステータス 400
原因：画像のサイズが規定外。画像は 2500×1686px・1MB以下です。
      お渡しした _final.jpg であれば問題ありません。

症状：ステータス 413
原因：画像が1MBを超えている。

症状：ステータス 415
原因：画像の形式が異なる。
      実行ログの「送信するファイルサイズ」が、417455（A）、
      465959（B）と一致しているか確認してください。

症状：「No item with the given ID could be found」
      または Drive関連のエラー
原因：FILE_ID_A または FILE_ID_B が間違っている。
      手順1でファイルIDを取り直してください。

症状：「Exception: 承認が必要です」「権限がありません」
原因：初回の権限承認を行っていない。
      手順5の「初回のみ」の操作を行ってください。

症状：「ReferenceError: ○○ is not defined」
原因：コードの貼り付けが途中で欠けている。
      手順3のコードを、すべてコピーし直してください。

症状：プロパティの値が反映されない
原因：「スクリプト プロパティを保存」を押していない。
      手順4を確認してください。
