============================================================
リッチメニュー画像アップロード手順書（PowerShell版）
============================================================

【この手順書の位置づけ】
Postmanで画像アップロード（415エラー）がうまくいかない場合の代替手順です。
画像アップロードの2回分（A・B）だけをPowerShellで行います。
それ以外の手順（メニュー作成、デフォルト設定、エイリアス作成など）は、
これまで通りPostmanで行って問題ありません。

【事前に必要なもの】
・Aのリッチメニュー作成済みで、richMenuId_A を控えている
・Bのリッチメニュー作成済みで、richMenuId_B を控えている
・チャネルアクセストークン
・画像ファイル2枚（同じフォルダに保存しておく）
    richmenu-pre_final.jpg      （Aの画像）
    richmenu-shinken_final.jpg  （Bの画像）


------------------------------------------------------------
手順1：PowerShellを画像のフォルダで開く
------------------------------------------------------------

1. エクスプローラーで、画像2枚を保存したフォルダを開く
2. 上部のアドレスバー（フォルダの場所が表示されている欄）をクリックする
3. 中身を消して「powershell」と入力し、Enterキーを押す
4. 青い（または黒い）PowerShellの画面が開く

※ これで、そのフォルダが作業場所になった状態でPowerShellが開きます。


------------------------------------------------------------
手順2：ファイルが正しいか確認する
------------------------------------------------------------

PowerShellに以下を貼り付けてEnterを押します。

(Get-Item .\richmenu-pre_final.jpg).Length
(Get-Item .\richmenu-shinken_final.jpg).Length

■ 期待される結果
417455
465959

・上の数字が 417455（A）、下の数字が 465959（B）になっていれば、
  ファイルは正しいものです。手順3へ進んでください。
・違う数字が表示された場合は、ダウンロード時にファイルが別の内容に
  変わっている可能性があります。表示された数字を控えて相談してください。
・「見つかりません」と表示された場合は、フォルダが違うか、
  ファイル名が違っています。ファイル名を確認してください。


------------------------------------------------------------
手順3：トークンとIDを変数に入れる
------------------------------------------------------------

以下の3行を、{ } の部分を実際の値に書き換えてから貼り付け、Enterを押します。
（{ } の括弧自体も消して、値だけを引用符の中に入れてください）

$token = "amxg/VZETTECi1jcqDmjymR5JDc1tGPKeDBNb9+UFTRzFaZjs0LJ8PJFCLSELG/QSzohN/6Etf0+mMnCw8LnY3I1JjqMq8sfb71dRA8YSn0ZGS5Crn99QOnCs13v9GK6L+9Eo3Z+wVwiQmltsjgmPAdB04t89/1O/w1cDnyilFU="
$idA   = "richmenu-8c46907e48156f3bfbc4fe0c88e5a66e"
$idB   = "richmenu-84af36d9159e2746dd816c963fd2a0c2"

■ 書き方の例
$token = "ENtYB0RGByLBTB...（長い文字列）..."
$idA   = "richmenu-347a5d5946872e9c3fe11e5fd5de8cb5"
$idB   = "richmenu-0123456789abcdef0123456789abcdef"

※ 引用符（"）は半角です。
※ トークンの前後にスペースや改行が入らないようにしてください。
※ このPowerShell画面を閉じると変数は消えます。閉じた場合は
  この手順3からやり直してください。


------------------------------------------------------------
手順4：Aの画像をアップロードする
------------------------------------------------------------

以下を貼り付けてEnterを押します。

curl.exe -i -X POST "https://api-data.line.me/v2/bot/richmenu/$idA/content" -H "Authorization: Bearer $token" -H "Content-Type: image/jpeg" -T ".\richmenu-pre_final.jpg"

■ 成功した場合
HTTP/1.1 200 OK
...
{}

と表示されます。「200 OK」が出ていれば成功です。

※ 「curl」ではなく必ず「curl.exe」と入力してください。
  PowerShellの「curl」は別のコマンドで、動作が異なります。


------------------------------------------------------------
手順5：Bの画像をアップロードする
------------------------------------------------------------

以下を貼り付けてEnterを押します。

curl.exe -i -X POST "https://api-data.line.me/v2/bot/richmenu/$idB/content" -H "Authorization: Bearer $token" -H "Content-Type: image/jpeg" -T ".\richmenu-shinken_final.jpg"

■ 成功した場合
HTTP/1.1 200 OK
...
{}

と表示されます。


------------------------------------------------------------
手順6：アップロード結果を確認する（任意）
------------------------------------------------------------

LINEのサーバーに画像が保存されたことを確認したい場合は、
保存された画像をダウンロードして目で確認できます。

curl.exe -X GET "https://api-data.line.me/v2/bot/richmenu/$idA/content" -H "Authorization: Bearer $token" -o check-A.jpg
curl.exe -X GET "https://api-data.line.me/v2/bot/richmenu/$idB/content" -H "Authorization: Bearer $token" -o check-B.jpg

同じフォルダに check-A.jpg と check-B.jpg が保存されます。
開いて、リッチメニューの画像が表示されれば、アップロードは成功しています。


------------------------------------------------------------
手順7：Postmanの作業に戻る
------------------------------------------------------------

画像アップロードが完了したら、Postmanで以下の続きを行ってください。

・デフォルトメニューの設定（Aを全員に表示）
・エイリアスの作成（richmenu-alias-pre と richmenu-alias-shinken の2つ）

※ すでに完了している手順はスキップして構いません。


------------------------------------------------------------
別の方法：Invoke-RestMethod を使う場合
------------------------------------------------------------

curl.exe がうまく動かない場合は、PowerShell標準のコマンドでも
同じことができます。手順3で変数を入れた後に、以下を実行します。

【Aの画像】
Invoke-RestMethod -Method Post -Uri "https://api-data.line.me/v2/bot/richmenu/$idA/content" -Headers @{ Authorization = "Bearer $token" } -ContentType "image/jpeg" -InFile ".\richmenu-pre_final.jpg"

【Bの画像】
Invoke-RestMethod -Method Post -Uri "https://api-data.line.me/v2/bot/richmenu/$idB/content" -Headers @{ Authorization = "Bearer $token" } -ContentType "image/jpeg" -InFile ".\richmenu-shinken_final.jpg"

■ 成功した場合
エラーが表示されず、何も出力されずにプロンプトに戻ります。
（赤い文字のエラーが出なければ成功です）


------------------------------------------------------------
つまずきやすいポイント
------------------------------------------------------------

症状：401 Unauthorized
原因：トークンの入力ミス、または前後にスペースが入っている。
      手順3の $token の行を入れ直してください。

症状：404 Not Found
原因：richMenuId が間違っている、または削除済みのメニューのID。
      Postmanで GET https://api.line.me/v2/bot/richmenu/list を送り、
      現在存在するIDを確認してください。

症状：413 Payload Too Large
原因：画像が1MBを超えている。_final.jpg を使っていれば発生しません。

症状：415 Unsupported Media Type
原因：画像の中身が正しいJPEGではない。手順2のファイルサイズ確認で、
      417455 / 465959 になっているか確認してください。

症状：「ファイルが見つかりません」と表示される
原因：PowerShellを開いたフォルダに画像がない。
      手順1に戻り、画像があるフォルダで開き直してください。

症状：「curl.exe : 用語として認識されません」
原因：Windowsが古い場合に発生します。
      「別の方法：Invoke-RestMethod を使う場合」の手順を使ってください。

症状：$idA などの変数が空になっている
原因：PowerShellを閉じて開き直した。手順3をやり直してください。
      （確認：「$idA」と入力してEnterで、中身が表示されます）


------------------------------------------------------------
セキュリティ上の注意
------------------------------------------------------------

・チャネルアクセストークンは、そのチャネルを操作できる「鍵」です。
  他人に見せたり、チャットやメールに貼り付けたりしないでください。
・PowerShellの画面のスクリーンショットを共有する際は、
  トークンの部分が映っていないことを確認してください。
・作業が終わったら、PowerShellの画面は閉じてください。
  （閉じると変数に入れたトークンも消えます）
